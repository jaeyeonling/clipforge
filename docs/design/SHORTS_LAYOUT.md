## 0. 최종 결정 (2026-10-18 저녁) — `card` + 손글씨 제목 띠

친구가 돌려본 뒤 **`review/ep59/shorts_title/02_story_10-44_0.76.mp4` 형태로 확정**했다(보내온 영상은 그 파일 그대로, 36.4초 재인코딩본).
아래 1~7절의 @마골 분석·`feed`·`ledger` 제안은 그 **전에** 한 검토이며, 선택되지 않았다. 코드와 문서에 남기되 기본값은 아니다.

확정 포맷의 구성 요소 (위→아래, 1080×1920):
| 영역 | 내용 | 구현 |
|---|---|---|
| 제목 띠 | 종이 질감 + 손글씨(나눔펜) 2줄, 득템 훅("7시간 정도 파밍했는데 / 탈라샤갑옷 · 신타이탄 직득!") | `topband.title_band`, `shorts.hook_lines` |
| 게임 | 원본 세로 전체 높이를 9:16 폭으로 크롭. **템 창(소지품/캐릭터)이 열리면 그쪽으로 즉시 컷** — 팬 없음 | `render.crop_track` + `ui_state`, `--ease 0` |
| 대사 자막 | 게임 하단 HUD 위, 흰 글자 + 검은 테두리, 전사 단어 경계로 분할 | `subtitles.cues_for_clip` + ASS |
| 채팅 | 별도 합성 없이 **방송 화면의 채팅 오버레이가 크롭 안에 그대로** 들어온다(닉·뱃지 포함) | 원본 레이아웃 의존 — 채팅 위치가 바뀌는 회차는 캘리브레이션에서 확인 |
| 시작/끝 | 콜드 오픈(인트로 없음), 발화 끝 +0.3s 에서 컷 | `snap_end` |

왜 이게 선택됐는지(추정, 친구 말은 "이 형태로 최종 결정"뿐): 방송 화면의 채팅·HUD·배너가 **그대로 남아 방송 느낌을 유지**하고, 손글씨 제목이 채널 톤(수기 득템 배너)과 이어진다. feed 처럼 텍스트를 다시 그리면 깔끔하지만 스트리머 방송 같지 않다.

남은 변수 (다음 피드백에서 확인): 제목 띠 문구 규칙(시간+득템 vs 가치 숫자), `--top chat`(줌 구간에 채팅 카드) 쓸지, 자막 위치/크기, 하단 채팅이 잘리는 회차 대응.

## 4. 제안: 레이아웃 `ledger` (득템 장부)

마골의 개념은 유지하되, 채널 고유 모티프 두 개(득템 로그·가치 메모)를 **구역으로 승격**한다.

```
  0~100   [기준 채널]                               [DAY 59 · 노거래 맨땅]   ← 브랜드 칩(노랑) + 카운터 칩
110~718   ┌────────────── 게임 화면 16:9 전체 ──────────────┐
          │  (우상단) ┃“헐 지참 나왔어요??”┃ ← 시청자 반응 하이라이트: 노란 말풍선 칩, 3초
          │                                                   │
          │                 와, 뭐야!   ← 발화 자막: 하단 중앙, 흰+검은 테두리, 상자 없음        │
          └───────────────────────────────────────────────────┘  노란 밑줄 6px
750~1010  ┌ 오늘 득템 ─────────────┐ ┌ 메모 ──────────┐
          │ · 화염5/3주얼           │ │ 지존참          │  ← 득템 로그: 배너 OCR 누적, 현재 것 ★노랑
          │ · 슬가                  │ │ 현금 7만원↑     │  ← 가치 메모: 메모장 모티프(미색+손글씨), value 없으면 옵션만
          │ ★ 3맥20어레20피         │ │ 3맥 20어레 20피 │
          └─────────────────────────┘ └────────────────┘
1040~1580  시청자 반응                                           ← 닉 없는 채팅 피드 3~5줄, 54px, 최신이 아래
1640~      래더 12기 59일차 · 지존참 직득 #디아블로2 …            ← 안전영역: 보조 정보만
```
인트로(0~1.5s): 마골식 축소 화면이 아니라 **스트리머 장편의 자기 방식** — 첫 프레임 위에 노랑+검은 테두리 제목 "래더 12기 노거래 맨땅 59일차" 한 줄과 득템 훅 한 줄. 채널 장편과 같은 얼굴이라 구독자에게 즉시 인식된다.

타입 스케일: 디스플레이 96(인트로·강조) / 본문 54(피드·발화) / 캡션 32(라벨·메모 보조). 색: 배경 #0E0D0C, 패널 #1A1816, 글자 #F5F2E8, 악센트 #F0F660 하나, 빨강은 가치 숫자에만.
규칙: 한 순간에 큰 것 하나(하이라이트 칩이 뜨면 발화 자막은 작게 유지), 구역은 고정, 하단 300px·우측 120px 에 중요 정보 금지.

마골과 다른 점: 채팅 강조의 위치(화면 하단 큰 줄 → 우상단 말풍선 칩), 피드 아래가 아니라 **피드 위에 득템 로그·가치 메모 구역**, 돌 프레임 대신 노란 밑줄 1개, 인트로는 축소 화면이 아닌 장편 제목 방식.

레퍼런스 원칙 대조: 고정 존 ✅ / 한 순간 큰 것 하나 — 칩(44)과 발화(54)가 동시에 뜰 수 있음 → 칩 표시 중엔 발화 자막을 44 로 ⚠ / 타입 3단 ✅ / 악센트 1개 — 노랑 + 메모 빨강 2개 → 빨강은 **가치 숫자에만** 허용 ✅ / 안전영역 — 피드 끝 1580 은 하단 672 기준(1248) 침범, 실제 UI(y>1680) 기준은 통과 → v1: 피드를 1030~1560 으로 두되 **마지막 줄은 보조 정보 수준**으로 간주, 핵심(장부·메모)은 1248 위에 ✅ / 콜드 오픈 — v0 의 1.6초 정지 인트로는 레퍼런스 9종 전부와 어긋남 → v1: **영상은 바로 재생, 제목만 1.2초 오버레이**(풍월량·스트리머 장편 방식).

## 6. v1 변경 요약
1. 인트로: 축소·정지 없음. 0~1.2s 동안 영상 위에 노랑+검은 테두리 제목 2줄(회차 / 득템 훅) 오버레이 후 페이드.
2. 채팅 하이라이트 칩: 영상 좌상단(x 40~, 우측 192px 금지). 표시 중 발화 자막 축소.
3. 시청자 반응 피드: 폭 ≤ 880px, 4줄, 54px. 하단 1600 이하엔 해시태그만.
4. 득템 장부: 배너의 **현재 전체 상태**(appear/append 누적)에서 토큰, 현재 것 ★. 메모 카드는 가치 데이터 없으면 옵션만.
5. 색: 배경·패널·글자 + 노랑 1개. 빨강은 가치 숫자 전용.
