# clipforge 사용 안내 (스트리머용, 한 장)

방송 편집본을 넣으면 쇼츠 초안을 뽑아 주고, "쓸 만함 / 안 씀"을 누를수록 다음 회차부터 취향에 맞춰 가는 프로그램이에요.
화면 안에서 낯선 말에 마우스를 올리면 설명이 떠요. 막히면 **도움말** 탭을 보세요.

## 1. 설치
1. `clipforge-Setup-x.y.z.exe` 를 실행해요. 관리자 권한은 필요 없어요.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 → **추가 정보** → **실행**. (아직 코드 서명이 없어서 떠요. 바이러스 아니에요.)
3. 백신이 막으면 `clipforge` 폴더를 예외로 넣어 주세요.

## 2. 첫 실행 (한 번만)
처음 켜면 분석 엔진 구성요소를 내려받아요. 파이썬 런타임 · GPU 가속(NVIDIA 있으면 자동 선택) · FFmpeg · 음성 인식 모델. 합쳐서 약 3.3GB, 회선에 따라 5~30분.
창을 닫아도 트레이(시계 옆 아이콘)에서 계속 받아요. 다 받으면 화면이 열려요.
인터넷 없이 설치하는 경우: USB 의 `release` 폴더를 받았으면, 폴더 안 `설치안내.txt` 대로 하면 돼요.

## 3. 영상 넣기
왼쪽 아래 **영상 넣기** 버튼, 또는 영상을 창에 **끌어다 놓기**. 여러 개 한 번에 돼요.
- 영상은 복사하지 않아요. 원본 파일을 옮기거나 지우면 다시 넣어야 해요.
- 위 선택창은 **편집본 → 쇼츠** 그대로 두세요. (원본 녹화를 넣어 편집 포인트를 뽑는 모드는 따로 있어요.)
- 유튜브 제목을 같이 적어 두면 제목의 득템 이름을 1순위 정답으로 써요. 선택이에요.

## 4. 분석 실행
**실행** 탭 → 파란 **쇼츠 초안 만들기** 버튼 하나. 4K 10분 편집본 기준 약 10분. 큰 숫자로 진행률과 남은 시간이 보이고, 창을 닫아도 트레이에서 계속 돌아요.
끝나면 **쇼츠 초안** 탭으로 자동으로 넘어가요. 주의 표시(예: 화면 영역 점검)가 뜨면 **화면 영역** 탭에서 미리보기를 한 번 보세요.
화면 위 "다음" 줄이 지금 할 일을 알려줘요.

## 5. 초안 보고 판정
세로 초안 영상이 순위대로 나와요. 재생해 보고
- **쓸 만함** / **안 씀**. 안 씀을 누르면 이유를 하나 골라요 (재미없음 / 임팩트없음 / 중복 / 잘림 / 맥락없음 / 기타).
- 키보드: ← → 이동, **K** 쓸 만함, **N** 다음 숫자 1~6 이유, Space 재생, **C** 두 개 나란히 비교, Esc 닫기
판정은 자동 저장되고, 6개 이상 쌓이면 다음 초안부터 순위에 반영돼요. 바뀐 기준은 설정에서 고급 기능을 켠 뒤 기록 탭에서 볼 수 있어요. 같은 버튼을 다시 누르면 취소.

## 6. 결과 가져가기
쇼츠 초안 탭 위 **초안 폴더** = 세로 mp4 + 자막(srt) · **Premiere XML** = 세로 시퀀스 파일 · **리뷰 XML** = 원본 전체 + 후보 트랙 + 마커.
Premiere 에서 파일 → 가져오기 로 XML 을 열면 시퀀스가 생겨요. (처음 한 번은 같이 확인해요.)

## 7. 업데이트
새 버전이 있으면 "새 버전이 준비됐어요" 창이 한 번 뜨고, 화면 위에 한 줄이 남아요. **지금 적용하고 다시 시작** 을 누르면 보통 1분 안에 끝나요(재설치 없음). 작업 중이면 끝난 뒤에 눌러요. "나중에"를 누르면 조용히 기다려요.

## 8. 뭔가 안 될 때
빨간 카드에 **원인과 할 일**이 적혀 있어요. **같은 설정으로 다시 실행** 으로 대부분 해결돼요.
안 되면 **설정 → 피드백 zip 만들기** → 생긴 파일을 카톡으로 보내 주세요. 영상은 안 들어가요.
오른쪽 위 상태 칩(준비 완료 / 느리게 동작 / OO 없음)에 마우스를 올리면 환경 문제가 뭔지 보여요.

## 9. 라이브 탭 (실험 기능)
방송 중 화면에서 세트·유니크 템 이름을 읽어 "배너에 추가?" 로 물어보고, 승인하면 득템 배너 텍스트(OBS 텍스트 소스)에 넣어요. 게임 중엔 **Ctrl+Alt+Y** 추가 · **Ctrl+Alt+N** 무시 · **Ctrl+Alt+M** 북마크.
아직 실방송에서 검증 전이라 **승인 모드만** 쓰고, 이상하면 바로 정지해 주세요. 방송에 자동으로 뭔가 나가는 일은 없어요.

## 10. 복사·붙여넣기
글자를 드래그하고 오른쪽 클릭하면 복사 메뉴가 떠요. 입력칸에서는 Ctrl+C / Ctrl+V 도 돼요.

---
폴더: 영상·결과·판정은 `%LOCALAPPDATA%\clipforge\data`, 로그는 설정 탭 "로그 열기". 프로그램을 지워도 이 폴더는 남아요.
