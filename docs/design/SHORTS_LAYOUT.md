# 쇼츠 레이아웃 설계 — 원리 추출 → 레퍼런스 → 기준 채널 고유 구조 (v0, 2026-10-18)

> 목표: 레퍼런스(@마골)를 복제하지 않는다. 왜 깔끔한지 원리를 뽑고, 비슷한 구조의 다른 사례를 보고, 핵심 개념만 가져와
> **기준 채널의 색깔**(노랑+검은 테두리 제목, "노거래 맨땅 N일차" 서사, 득템 배너 누적, 현금 가치 메모)로 재구성한다.

## 1. 레퍼런스 분석: @마골 쇼츠는 왜 깔끔한가

관찰 (3편, 2026-10-18): 돌 테두리 프레임 / 상단 채널 띠 / 16:9 게임 화면 전체 / 화면 좌상단 작은 발화 자막 / 화면 하단 큰 강조 한 줄 /
회차 라벨 띠 / 고정 한 줄 / 닉네임 없는 채팅 피드 / 하단 장식 바. 인트로 1.5초: 화면 축소 + 2색 제목 → 풀 사이즈 컷.

깔끔함을 만드는 요소 (원리로 추출):
| 원리 | 마골에서의 구현 | 반대 사례(지저분해지는 이유) |
|---|---|---|
| **구역이 고정**되어 움직이지 않는다 | 영상·자막·라벨·피드의 자리가 모든 쇼츠에서 동일 | 자막 위치가 장면마다 바뀜, 요소가 겹침 |
| **한 순간에 큰 것 하나** | 화면 하단 큰 줄은 한 번에 하나. 발화 자막은 작고, 피드는 중간 | 훅·자막·채팅이 동시에 큰 글씨로 경쟁 |
| **영상은 자르지 않는다** | 16:9 전체. UI 글자는 작아지지만 "무슨 상황인지" 가 항상 보임 | 정사각 크롭으로 툴팁·인벤·미니맵이 잘림 (우리 1차 피드백) |
| **타입 스케일 3단** | 큰 줄(강조) / 중간(피드·라벨) / 작은(발화) | 크기가 5~6종류 |
| **팔레트 1 악센트** | 어두운 돌 배경 + 흰 글자 + 금색 1개 | 색이 많고 배경이 밝음 |
| **채팅 = 리액션 화면** | 페이스캠 대신 닉 없는 채팅이 반응을 보여줌. 닉을 빼서 소음 제거 | 닉·이모지·배지가 붙은 채팅 원본 |
| **인트로가 정체성** | 축소 화면 + 시리즈 제목 2색 — 1.5초에 "이 채널"임을 알림 | 콜드 오픈만 있거나 5초 넘는 로고 |
| **여백·안전영역** | 중요 정보는 중앙 60%에, 하단은 장식 | 하단 300px(쇼츠 UI)·우측 120px(버튼)에 글자 |

그대로 가져올 **개념**: 고정 구역, 영상 전체, 큰 것 하나 규칙, 3단 타입 스케일, 1 악센트, 닉 없는 채팅 피드, 1.5초 인트로.
가져오지 않을 **구현**: 돌 테두리 프레임, 화면 하단 큰 줄 위치, 회차 띠 모양, 2색 제목 배치, 피드의 폰트·배경.

## 2. 유사 레퍼런스 (리서치 결과는 §2 부록에 추가 예정)

## 3. 기준 채널의 색깔 (채널 관측)
- **색**: 썸네일·인트로 제목이 전부 밝은 노랑 **#F0F660**(ep59 인트로 실측 RGB 240,246,96) + 검은 테두리. 포인트는 빨강(화살표). 배경은 게임 스크린샷의 어두운 톤.
- **글씨**: 둥글고 굵은 디스플레이체(썸네일 캡슐 제목). 우리 번들에선 BlackHanSans 가 가장 가깝다(무료·OFL).
- **서사 장치**: "래더 N기 노거래 맨땅 M일차" 카운터(모든 제목·인트로), **득템 배너**(방송 중 누적 목록 — 채널 고유 습관), **현금 가치 메모**(메모장을 화면에 띄워 "현금 30만원이상"), 채팅 줌인.
- **톤**: 장식 없이 직설적. 제목이 곧 사건("… 직득했습니다 !!").

## 4. 제안: 레이아웃 `ledger` (득템 장부)

마골의 개념은 유지하되, 채널 고유 모티프 두 개(득템 로그·가치 메모)를 **구역으로 승격**한다.

```
  0~100   [기준 채널]                               [DAY 59 · 노거래 맨땅]   ← 브랜드 칩(노랑) + 카운터 칩
110~718   ┌────────────── 게임 화면 16:9 전체 ──────────────┐
          │  (우상단) ┃“헐 지참 나왔어요??”┃ ← 시청자 반응 하이라이트: 노란 말풍선 칩, 3초
          │                                                   │
          │                 와, 뭐야!   ← 발화 자막: 하단 중앙, 흰+검은 테두리, 상자 없음        │
          └───────────────────────────────────────────────────┘  노란 밑줄 6px
750~1010  ┌ 오늘 득템 ─────────────┐ ┌ 메모 ──────────┐
          │ · 화염5/3주얼           │ │ 지존참          │  ← 득템 로그: 배너 OCR 누적, 현재 것 ★노랑
          │ · 슬가                  │ │ 현금 7만원↑     │  ← 가치 메모: 메모장 모티프(미색+손글씨), value 없으면 옵션만
          │ ★ 3맥20어레20피         │ │ 3맥 20어레 20피 │
          └─────────────────────────┘ └────────────────┘
1040~1580  시청자 반응                                           ← 닉 없는 채팅 피드 3~5줄, 54px, 최신이 아래
1640~      래더 12기 59일차 · 지존참 직득 #디아블로2 …            ← 안전영역: 보조 정보만
```
인트로(0~1.5s): 마골식 축소 화면이 아니라 **스트리머 장편의 자기 방식** — 첫 프레임 위에 노랑+검은 테두리 제목 "래더 12기 노거래 맨땅 59일차" 한 줄과 득템 훅 한 줄. 채널 장편과 같은 얼굴이라 구독자에게 즉시 인식된다.

타입 스케일: 디스플레이 96(인트로·강조) / 본문 54(피드·발화) / 캡션 32(라벨·메모 보조). 색: 배경 #0E0D0C, 패널 #1A1816, 글자 #F5F2E8, 악센트 #F0F660 하나, 빨강은 가치 숫자에만.
규칙: 한 순간에 큰 것 하나(하이라이트 칩이 뜨면 발화 자막은 작게 유지), 구역은 고정, 하단 300px·우측 120px 에 중요 정보 금지.

마골과 다른 점: 채팅 강조의 위치(화면 하단 큰 줄 → 우상단 말풍선 칩), 피드 아래가 아니라 **피드 위에 득템 로그·가치 메모 구역**, 돌 프레임 대신 노란 밑줄 1개, 인트로는 축소 화면이 아닌 장편 제목 방식.
