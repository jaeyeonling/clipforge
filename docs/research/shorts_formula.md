관찰: 구독자 수와 무관하게 "득템 + 숫자 훅 + 서사"가 100만을 만든다. 대형 스트리머의 날것 클립은 구독자 대비 저조.

### 구조
- **길이 2종**: (a) 순수 페이오프 9~25초 — 아이템이 0~3초에 이미 화면에 있고 리액션이 본체. (b) 서사형 27~60초 — 드랍(5~10초) → 툴팁 확대·감별 → 가치(원/자룬/Divine) 또는 반전("But...", "10초만에 나락")으로 끝.
- **첫 1~2초**: 한국은 첫 프레임부터 상단 검은 띠에 2줄 텍스트 훅(흰+노랑). 해외는 페이스캠 리액션 + 게임 화면 동시, 아이템 라벨이 이미 보임.
- **끝**: 끝난 직후 컷(루프 유도) 또는 "풀버전" CTA.
- **가치 표기**: 한국 = 원화(10만·80만·400만·4천만원) 또는 룬 단위(25자룬·17베르룬). 해외 = Ber/Jah·Divine·Mirror, 드랍 확률("1:387,978"), 시세("x50 Current Market Price").
- **음성/채팅**: 한국은 스트리머 발화를 하단 대형 자막으로 전사("뭐야 이거?!", "20/20이 으뜸 아닙니까"), 채팅 스크린샷을 팩트체크로 삽입. 해외는 얼굴 표정이 주 리액션, 자막 한 줄.

### 세로 레이아웃
- 한국 A(클립 채널형): 상단 25% 검은 띠 + 2줄 제목, 중단은 16:9 화면을 **인벤토리/툴팁 중심 크롭**(캐릭터가 아님), 빨간 화살표, 하단 대형 자막.
- 한국 B(여캠형): 페이스캠 중앙 + 상단 제목 + 하단 자막.
- 한국 C(감정 교육형): 툴팁 확대 + 옵션별 주석 박스.
- 해외: 상단 40~50% 페이스캠 / 하단 게임 세로 크롭 스택. 게임부는 툴팁을 중앙으로.

### 제목 패턴
- 한국: 숫자+원화, 최상급(역대급·지존·최초·세계 1위·인생), 의문형("이거 진짜에요?"), 뉴비/고인물 대비, 비유("반포자이 부츠"), 반전, ㄷㄷ·ㅋㅋ.
- 해외: 4~6단어 궁금증형("I Finally Found It! But..."), "FIRST ... EVER". 해시태그 없음이 성과 좋음.

### 한국 vs 해외
한국은 텍스트 밀도와 현금 환산이 핵심(상단 제목·하단 전사·원화 숫자 세트). 해외는 페이스캠+게임 스택의 날것 클립이 표준이고 텍스트 최소. 양쪽 공통 승리 공식: **≤20초로 짧게 자르거나, 30~45초 안에 "드랍 → 툴팁 → 숫자 → 반전" 서사 + 첫 프레임 숫자 든 2줄 텍스트 훅**.

## B. 일반 쇼츠 공식 (출처 있음 / 민간 지혜 구분)

### 출처 있음
- Inflow Network(쇼츠 5,400개, 2023): 총 조회 0~10s 7.7만 / 20~30s 46만 / 30~40s 69만 / 40~50s 80만 / 50~60s 170만. 최빈 30~40초.
- Buffer(틱톡 110만 개): 60초 초과가 30~60초 대비 도달 +43%, 시청시간 +64%. 단 60초 초과는 전체 12%. "길이보다 훅 강도·품질".
- Adobe Express 설문(507명): 조회는 30초 미만, 구독 전환은 30초 미만과 30~60초 동률.
- YouTube "Stayed to watch" 지표는 공식 임계 비공개. 3rd-party 벤치마크 70~80%. 2025-03-31부터 쇼츠 조회수는 즉시 1회 카운트(루프가 조회수를 부풀림).
- 자막: Meta 테스트 자막 광고 시청시간 +12%. 무음 시청 다수.
- 안전영역(1080×1920): 상단 108~150px, 하단 270~320px, 우측 40~120px 비움. 공용 "중앙 900×1400".
- 도구 루브릭: Opus Clip = Hook/Flow/Value/Trend(0~99). Klap = hook strength/emotional peak/dialogue clarity/pacing. Vizard = hook/takeaway/독립 완결성. Eklipse(게임) = 게임 UI 이벤트(킬피드·승리) + 마이크 볼륨 스파이크 + 고강도 게임 오디오 + 음성 트리거, 신형은 액션 밀도·연속성·장르 튜닝·가변 길이. 공통 분모: 훅 / 감정 피크 / 완결성 / 트렌드 + (게임) UI 이벤트·채팅 급증.

### 민간 지혜 (수렴하지만 수치 미출처)
- 훅: 피크 직전 1~2초 하드컷(액션 훅) / 리액션 먼저 → 원인 되감기(리액션 훅) / 3~5단어 텍스트 훅. "모든 클립 앞 5~7초 자르기". 틱톡은 가장 빠른 스와이프, 쇼츠는 3~4초 여유.
- 구조: Setup(저HP·1v3 "before") → Buildup(한 플레이만, 줌/슬로모) → Payoff(결과 화면 + 진짜 리액션). 원본 아크는 5~15초 안에 완결. "바이럴의 80%는 소스 클립이 결정".
- 한국(streamhub): "안녕하세요로 시작하면 100% 이탈". 0~3초 결과 → 4~15초 빌드업 → 16~20초 유도. 5초마다 구도/줌/텍스트 변화. 3시간 방송에서 "가장 긴장감 넘치는 40초".
- 루프: 마지막 프레임이 첫 장면과 이어지게.
- 실패 모드: 느린 페이드인, 세팅 보이스오버, 메뉴·로딩·이동, 첫 2초 무음, 긴 빌드업, 문맥 없는 소리침, 크롭에 캐릭터·툴팁 잘림, 작은 자막, 자막이 하단 UI와 겹침, 패딩으로 길이 늘리기.

## C. 한국 방송 클립 채널 관례

- 순간 선정: **채팅·도네 반응 폭발 지점 우선**(Captus는 치지직/SOOP 다시보기의 채팅 밀도 그래프만으로 하이라이트 추출). 오디오 피크(비명·함성). 결과형(역전·보스·실수). 완결성(앞뒤 맥락 없이 이해).
- 디아2 = **드랍 → 감별 클릭 → 함성**(참타호 "끼야아아악" 모델). 던파 = 증폭/강화 성공·실패 + 사건성 리액션(채팅 충돌), 레이드 레이스, 에픽 득템.
- 길이: 15~30초가 가장 효과적(15~60 범위). 공식 0~3초 훅 / 4~12초 핵심 / 13~15초 반전.
- 시작: 결과 먼저. "도입 3초 승리 환호 → 전개 10초 위기 압축 → 결말 7초 재환호".
- 끝: 감정 정점으로 끊기. "방송 보러 오세요"는 지루.
- 자막: 상단 훅은 두꺼운 폰트, 대사는 얇게. 흰·검·노랑·빨강·초록·민트, 테두리, 4줄 이상 금지, 마침표 생략.
- 외주 공고의 공식: "훅 자막 + 리듬컷 + 효과음/밈 + 가독 자막 + 9:16 안전영역". 단가: 단순 자막 숏폼 건당 1.2~1.5만원, 롱폼 분당 1.5~1.8만원.
- 채팅 줌인 규칙은 명문화된 것 없음 (스트리머는 이미 사용 중).
