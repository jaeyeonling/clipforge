# clipforge 사용 안내 (스트리머용, 한 장)

방송 편집본을 넣으면 쇼츠 초안을 뽑아 주고, 판정(쓸만함/아님)을 기억해서 점점 취향에 맞춰 가는 프로그램입니다.

## 1. 설치
1. `clipforge-Setup-x.y.z.exe` 를 실행합니다. 관리자 권한은 필요 없습니다.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 → **추가 정보** → **실행**. (아직 코드 서명이 없어서 뜹니다. 바이러스 아닙니다.)
3. 백신이 막으면 `clipforge` 폴더를 예외로 넣어 주세요.

## 2. 첫 실행 (한 번만)
처음 켜면 분석 엔진 구성요소를 내려받습니다. 파이썬 런타임 · GPU 가속(NVIDIA 있으면 자동 선택) · FFmpeg · 음성 인식 모델. 합쳐서 약 3.3GB, 회선에 따라 5~30분.
창을 닫아도 트레이(시계 옆 아이콘)에서 계속 받습니다. 다 받으면 화면이 열립니다.
네트워크 없이 설치하는 경우: USB 의 `release` 폴더를 받았으면, 폴더 안 `설치안내.txt` 대로 주소 파일 하나만 만들어 두면 됩니다.

## 3. 회차 넣기
왼쪽 **"영상 파일 선택…"** 또는 영상을 창 왼쪽에 **끌어다 놓기**. 여러 개 한 번에 됩니다.
- 영상은 복사하지 않습니다. 원본 파일을 옮기거나 지우면 다시 등록해야 합니다.
- 위 선택창은 **편집본 → 쇼츠** 그대로 두세요. (원본 녹화를 넣어 편집 포인트를 뽑는 모드는 따로 있습니다.)
- 유튜브 제목을 같이 적어 두면 제목의 득템 이름을 정답으로 씁니다. 선택입니다.

## 4. 실행
**파이프라인** 탭 → 단계가 미리 체크돼 있음 → **실행**. 4K 10분 편집본 기준 약 10분. 남은 시간이 표시되고, 창을 닫아도 트레이에서 계속 돕니다.
끝나면 **후보** 탭으로 자동으로 넘어갑니다. 주의 표시(예: 화면 영역 점검)가 뜨면 캘리브레이션 탭을 한 번 보세요.

## 5. 후보 보고 판정
세로 초안 영상이 순위대로 나옵니다. 재생해 보고
- **keep** = 쓸 만함 · **no** = 안 씀(사유 하나 고르기: 재미없음 / 임팩트없음 / 중복 / 잘림 / 맥락없음)
- 키보드: ← → 이동, **K** keep, **N** 다음 숫자 1~6 사유, Space 재생, **C** 두 개 나란히 비교
판정은 자동 저장되고, 다음 회차부터 순위에 반영됩니다. 같은 버튼을 다시 누르면 취소.

## 6. 결과 가져가기
후보 탭 위 **"초안 폴더"** = 세로 mp4 + 자막(srt) · **"Premiere XML"** = 세로 시퀀스 파일 · **"리뷰 XML"** = 원본 전체 + 후보 트랙 + 마커.
Premiere 에서 파일 → 가져오기 로 XML 을 열면 시퀀스가 생깁니다. (처음 한 번은 같이 확인해요.)

## 7. 업데이트
새 버전이 있으면 화면 위에 한 줄 뜹니다. **지금 적용** 을 누르면 몇 초 만에 끝납니다(재설치 없음). 작업 중이면 끝난 뒤 누르세요.

## 8. 뭔가 안 될 때
빨간 카드에 **원인과 할 일**이 적혀 있습니다. **같은 설정으로 다시 실행** 으로 대부분 해결됩니다.
안 되면 **설정 → 피드백 zip 만들기** → 생긴 파일을 카톡으로 보내 주세요. 영상은 안 들어갑니다.

## 9. 라이브 탭 (실험 기능)
방송 중 화면에서 세트·유니크 템 이름을 읽어 "배너에 추가?" 로 물어보고, 승인하면 득템 배너 텍스트(OBS 텍스트 소스)에 넣습니다. **Ctrl+Alt+M** 은 북마크.
아직 실방송에서 검증 전이라 **승인 모드만** 쓰고, 이상하면 바로 정지해 주세요. 방송에 자동으로 뭔가 나가는 일은 없습니다.

---
폴더: 영상·결과·판정은 `%LOCALAPPDATA%\clipforge\data`, 로그는 설정 탭 "로그 열기". 프로그램을 지워도 이 폴더는 남습니다.
